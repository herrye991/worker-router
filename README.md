A self-hosting-free LLM API gateway that runs entirely on Cloudflare: a single Worker serves both the OpenAI-compatible API and the admin dashboard (monorepo, single port), with Cloudflare D1 as the persistent database. No VPS, no Docker, no Redis, no long-running Node process.

## Features

- **OpenAI-compatible API**: `POST /v1/chat/completions` (non-streaming + SSE streaming), `GET /v1/models`
- **Providers**: OpenAI-compatible, Anthropic Messages, Google Gemini, Cloudflare Workers AI (extensible adapter interface)
- **Models**: public aliases mapped to provider-specific model IDs, capabilities, cost metadata, weights and priorities
- **Routing groups (combos)**: `single`, `round-robin` (D1 atomic counter), `weighted`, `fallback` with retryable-status policy, exponential backoff with jitter, and request deadline
- **Admin dashboard**: Overview, Endpoint & Key, Providers (test connection, fetch `/models`, one-click model registration), Models, Combos, Usage, Request Logs, Settings — password-only login (default `123456`)
- **Security**: admin session cookies (HttpOnly, SameSite=Lax, CSRF check), PBKDF2 password hashing, SHA-256 hashed client API keys (full key shown once), AES-GCM encrypted provider credentials
- **Observability**: request logs, per-provider and per-model usage, latency, error rate, estimated cost, timeseries
- **Single-port monorepo**: `wrangler dev` and `wrangler deploy` serve frontend + API on one Worker via the ASSETS binding

## Quick Start (local, single port)

```bash
npm install
npm --prefix frontend install
wrangler d1 create worker-router
# put database_id in wrangler.jsonc
npm run db:migrate:local
npm run seed:local        # deterministic mock provider + dev API key
cp .dev.vars.example .dev.vars
npm run dev               # builds frontend, serves dashboard + API on :8787
```

Open `http://localhost:8787` and log in with password `123456`.

Test chat:

```bash
curl http://localhost:8787/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer wr-local-dev-key-0123456789abcdef" \
  -d '{"model":"fast-chat","messages":[{"role":"user","content":"halo"}]}'
```

The seed registers model `mock-chat` and routing group `fast-chat` pointing at the local mock upstream (`/mock-upstream`).

## Deploy to Cloudflare

```bash
npm run db:migrate:remote
openssl rand -base64 32 | wrangler secret put ENCRYPTION_MASTER_KEY
openssl rand -hex 32 | wrangler secret put SESSION_SECRET
echo "change-me" | wrangler secret put ADMIN_PASSWORD
npm run deploy
```

Required secrets: `ENCRYPTION_MASTER_KEY` (AES-GCM for provider credentials), `SESSION_SECRET`, `ADMIN_PASSWORD` (dashboard login, password-only).

## API Contract

- Auth: `Authorization: Bearer <client-key>` (401 on missing, invalid, or expired keys)
- Errors: `{ "error": { "message", "type", "code", "request_id" } }` with correct HTTP status codes
- Streaming: `Content-Type: text/event-stream`, OpenAI chunk shape, `data: [DONE]` terminator; no fallback after stream start
- Capability-aware: tools are rejected with `unsupported_capability` when no eligible provider supports them
